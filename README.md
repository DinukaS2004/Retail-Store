# Retail Store UI

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

A **Retail Store UI** built using HTML and CSS for visual representation of a retail inventory system. This project focuses on front-end design without backend functionality.

## 📌 Features

- 🎨 **User Interface Design** – A static UI for retail store management.
- 🏷️ **Product Display** – Visual representation of products and categories.
- 🛒 **Cart Interface** – UI elements for adding items to a cart (non-functional).
- 📊 **Mock Reports & Dashboards** – Static reports for visualization.

## 🏗️ Tech Stack

- **Frontend:** HTML, CSS
- **Tools:** VS Code / Any text editor

## 🛠️ Setup & Installation

### Steps to Run
1. **Clone the repository**
   ```sh
   git clone https://github.com/DinukaS2004/Retail-Store.git
   cd Retail-Store
   ```
2. **Open the project in a browser**
   - Open `index.html` in any web browser.
